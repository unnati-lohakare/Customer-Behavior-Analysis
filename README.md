# Customer Behavior Analysis | Python, SQL & Power BI
Python, SQL, and Power BI project analyzing customer purchasing behavior, spending patterns, product preferences, discounts, subscriptions, and customer segments.

# 📌 Overview

This project analyzes customer purchasing behavior to identify spending patterns, product preferences, discount usage, subscription trends, and customer segments.

The project follows an end-to-end data analytics workflow, starting with data loading and Exploratory Data Analysis (EDA) in Python, followed by SQL-based business analysis in MySQL Workbench and interactive dashboard development in Power BI.

**Objective**: Transform raw customer data into meaningful business insights that can support better customer engagement, marketing strategies, and data-driven decision-making.

# 📂 Dataset

The dataset contains customer purchase and behavior information, including fields such as:

- Customer ID
- Age and Age Group
- Gender
- Item Purchased and Category
- Purchase Amount
- Review Rating
- Discount Applied
- Shipping Type
- Subscription Status
- Previous Purchases

# 🔄 Project Workflow

**1. Data Loading & Exploratory Data Analysis (Python)**

- Loaded the dataset into Google Colab.
- Explored the dataset structure, columns, and data types.
- Examined summary statistics and customer purchasing patterns.
- Investigated missing values, duplicate records, and data quality issues.

**2. Data Cleaning (Python)**

- Checked and handled missing values where necessary.
- Identified and handled duplicate records where appropriate.
- Reviewed data types and column consistency.
- Prepared the dataset for further analysis.

**3. Business Analysis Using SQL**

Used MySQL Workbench to answer business questions, including:

- What is the total revenue generated by male and female customers?
- Which discounted purchases exceeded the average purchase amount?
- Which products have the highest average review ratings?
- How do average purchase amounts compare between Standard and Express shipping?
- Do subscribers spend more than non-subscribers?
- Which products have the highest discount usage rates?
- How can customers be segmented into New, Returning, and Loyal groups?
- What are the top three most purchased products within each category?
- Are repeat buyers more likely to subscribe?
- Which age groups contribute the most revenue?

**SQL concepts practiced:** Aggregations, GROUP BY, ORDER BY, subqueries, CASE, Common Table Expressions (CTEs), and window functions.

**4. Power BI Dashboard**

Created an interactive Power BI dashboard to present customer behavior insights in a clear, business-friendly format.

The dashboard can be used to explore customer purchasing patterns, revenue contribution, product performance, discount trends, and subscription behavior, depending on the visuals and KPIs included in the report.

# 📈 Results & Business Insights

The analysis is designed to help identify:

- **Customer Overview:** Analyzed approximately **3.9K customers**, with an average purchase amount of **$59.76** and an average customer review rating of **3.75/5**.
- **Revenue Trends:** Clothing generated the highest category revenue at **104K**, followed by Accessories at **74K**, Footwear at **36K**, and Outerwear at **19K**.
- **Product Category Performance:** Clothing recorded the highest sales volume with **1,737 sales**, followed by Accessories **(1,240)**, Footwear **(599)**, and Outerwear **(324)**.
- **Customer Age Segmentation:** Young Adults contributed the highest revenue at **62K**, followed by Middle-aged customers **(59K)**, Adults **(56K)**, and Seniors **(56K)**. 
- **Subscription Behavior:** Approximately **73% of customers were non-subscribers**, while **27% had subscriptions**, highlighting an opportunity to explore strategies for increasing subscription adoption.
- **Purchasing Patterns by Age:** Young Adults recorded the highest sales volume at **1,028**, followed by Middle-aged customers **(986)**, Seniors **(944)**, and Adults **(942)**.

These findings can help businesses better understand their customers, evaluate purchasing behavior, and identify opportunities to improve marketing and customer retention strategies.

# 🚀 How to Run

Open the Google Colab notebook:

Run the notebook cells in order. If the notebook requires a local dataset, upload the dataset or update the file path as needed.

**Step 2: Run the SQL Queries**

2. Create or select the customer_behavior database.
3. Import the cleaned dataset into a table named customer.

5. Execute the queries to reproduce the business analysis.

Ensure the imported table and column names match those used in the SQL script.

1. Install Power BI Desktop.
2. Open Customer_Behavior_Analysis.pbix.
3. If prompted, update the data source path or connection settings.
4. Refresh the data if required.
5. Explore the dashboard visuals and available filters.
